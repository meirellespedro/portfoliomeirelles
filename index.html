Automação de Preenchimento de Formulários Web

AutoForm Desktop

Aplicação desktop que automatiza o preenchimento repetitivo de formulários web com Playwright, eliminando um fluxo manual e erros de digitação. Integração com gateway de pagamento (Mercado Pago, OAuth 2.0) para controle de acesso por licença, com dados persistidos no Supabase/PostgreSQL. Testes com Vitest e instalador empacotado com electron-builder.
